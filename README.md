# ComfyUI プロンプト注入 拡張機能

ComfyUI のプロンプト入力と画像生成をブラウザの専用タブで操作できる Chrome 拡張機能です。

## 機能

- **プロンプト注入** — テキストを ComfyUI のポジティブプロンプトノードに直接反映
- **ワンクリック生成** — ワークフローをそのまま使い、シードをランダム化して画像生成
- **プロンプト辞書** — よく使うプロンプトを登録・検索
- **生成履歴** — 過去の生成画像とプロンプトを一覧表示
- **外部フレーズ検索** — Web からプロンプトフレーズを検索
- **Ollama 連携** — ローカル LLM でプロンプトを自動生成
- **右クリックメニュー** — ページ上のテキストを選択してプロンプトに追加

## インストール

1. このリポジトリをクローンまたはダウンロード
2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択

## 設定

[`manifest.json`](manifest.json) の `host_permissions` に ComfyUI サーバーの URL を設定してください。

```json
"host_permissions": [
  "http://<ComfyUIのIPアドレス>:8188/*"
]
```

また [`background.js`](background.js) と [`popup.js`](popup.js) 内の `COMFYUI_BASE` も同じ URL に合わせてください。

> **注意：** デフォルトのソースコードには特定の IP アドレスがハードコードされています。このまま公開リポジトリにプッシュすると IP アドレスが外部に漏れます。上記の URL を自分の環境に書き換えてからコミットしてください。

## 動作環境

- Google Chrome (Manifest V3 対応)
- ComfyUI サーバーが起動済みであること
